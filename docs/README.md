# Documentation

These docs follow [Diátaxis](https://diataxis.fr/). Each page belongs to exactly
one of four types:

| Type | Directory | Purpose | Reader is |
| ---- | --------- | ------- | --------- |
| Tutorials | `tutorials/` | Learning by doing, start to finish | studying |
| How-to guides | `how-to/` | Steps to accomplish a specific goal | working |
| Reference | `reference/` | Accurate description of what exists | working |
| Explanation | `explanation/` | Background, context, and reasoning | studying |

If a page starts doing two jobs, split it. A how-to guide that stops to explain
design rationale should link to an explanation page instead.

Create a type's directory when its first page is written.
